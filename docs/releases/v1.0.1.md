Clipshot 1.0.1: uygulamada değişiklik yok; otomatik güncellemenin ilk gerçek denemesi.

- 1.0.0 bu sürümü kendisi bulur, indirir, SHA-256 ile doğrular ve kendini yeniler. İki sürüm de aynı sertifikayla imzalı olduğu için Ekran Kaydı izni korunur.
- Release betikleri artık GitHub'a SSH anahtarı olmadan, `gh` oturumuyla push ediyor.

## Kurulum

- **Homebrew:** `brew install --cask egekibar/tap/clipshot` (kuruluysa Clipshot kendini günceller; `brew upgrade --cask --greedy clipshot` da olur)
- **DMG:** aşağıdaki `Clipshot-1.0.1.dmg`. Ayrıntılar için [1.0.0 notları](https://github.com/egekibar/Clipshot/releases/tag/v1.0.0).
